Overview

Smart-study-panner is an all-in-one educational planning tool that combines personalized scheduling, predictive analytics, and emotion-aware interactions to optimize student success. The core features include:





Dynamic Schedule Generation: Creates conflict-free weekly timetables balancing study, sleep, and activities based on user preferences.



Multi-Target Prediction Pipeline: Utilizes sequential models to forecast student outcomes like exam scores, sleep, and extracurricular participation.



Real-Time Emotion Detection: Analyzes webcam input to infer emotional states, providing immediate, personalized feedback.



Interactive Web Application: Offers a user-friendly interface for schedule visualization, performance tracking, and personalized recommendations.



Robust ML Training & Logging: Implements comprehensive model training, evaluation, and detailed logging for reproducibility and tuning.
